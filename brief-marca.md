## Límites y funcionamiento
La captura de WhatsApp mostraba abierto 24 horas. No se publicó ese horario como compromiso, porque falta confirmación expresa de los horarios de cocina y atención.
No hay backend, cobros, envío automático ni calendario de disponibilidad. El formulario prepara la solicitud para que el visitante la envíe y el restaurante confirme.
Mapa integrado de Google más ruta externa y fondo local de ubicación si el mapa no carga. La ruta fue cotejada con Ramírez 725; coordenadas de Facebook próximas a -28.574387, -70.760749. El mapa integrado no cargó visualmente en la sesión local; su URL respondió HTTP 200. El enlace de ruta queda siempre visible.
No hay dominio definitivo, por lo que canonical, og:url y sitemap no se inventaron. Pasos pendientes de dominio documentados en README.
No se usaron reseñas, seguidores ni avatares como prueba social. Sí se conservan identidad y proceso culinario del propio negocio.
Sitio entregado localmente para que el usuario lo suba después a GitHub y Vercel.
